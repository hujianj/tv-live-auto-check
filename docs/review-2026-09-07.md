## Outcome

The implementation is not yet a successfully deployed replacement subscription.
Offline tests pass, but the latest complete local run stopped at required-channel
coverage. The protected production playlists have not been replaced by partial
diagnostic results. No rights approval or successful playback evidence was invented.

The scope is the current execution environment, not Liaoning stations, a regional
availability guarantee, or the television's broadband provider. Domestic Chinese
channels include explicitly identified Chinese-language Hong Kong, Macau and Taiwan
services. Foreign stations, including overseas Chinese stations, are excluded.

Transient failures receive bounded retries and remain available as recovery
candidates. A failed URL is not published as a supposedly working backup just
because an older observation passed. This deliberately prioritizes current
playback evidence over retaining a grace-period broken URL.

links, not a video relay. Encrypted/DRM streams, login/cookie-dependent URLs and
short-lived signed addresses are excluded.

withdrew the regional condition. There is no default approval of newly discovered
sources. Source metadata and latest fetch evidence are exported to the artifact
`source-inventory.json`, including candidate-only catalog links.

## Repairs in this continuation

- Accept interlaced `576i`/`1080i` resolution suffixes throughout identity and scope
  handling, including harmless whitespace. CCTV-4K is not counted as CCTV-4.
- Aborted strict rechecks now record actual checks and failures, retain original
  outputs, and distinguish candidate row counts from promoted row counts.
- Recheck CSV preserves the real source even for removed/failed rows.
- Diagnostic reports include broad-pass failures and distinguish unperformed
  checks (`null`) from a measured failure. Stale evidence cannot make an export ready.
- Metadata joins use canonical identity, URL and source; ambiguous origins and
  incompatible channel aliases cannot inherit each other's approval.
- Legacy source contribution counters are explicitly labeled as pre-policy
  parsing counts, separate from media-eligible and final output sources.
- The existing test entry point now runs 87 original and 24 pipeline tests, all passing.

## Remaining release blockers

1. Current approved, in-scope sources do not meet required core-channel coverage.
   Additional sources need dated usage evidence and fresh successful media checks.
2. The production bundle has historical cross-file inconsistencies: summary says
   2,042 lines while the files have 1,948; the family summary says 1,061 vs 1,007.
   Old signed URLs also fail the newer policy. Committed-bundle validation is
   intentionally still failing. Changing counters alone would not prove playback.
3. The repair branch is not merged or automatically deployed. A passing new full
   maintenance run and valid complete bundle are required before replacing main.
4. Container/video-track and HLS-progress evidence reduces false positives but
   does not establish full decoder compatibility, correct program identity, or
   continuous future availability.

The existing long-term TV subscription remains:
`https://cdn.jsdelivr.net/gh/hujianj/tv-live-auto-check@main/ku9-live.txt`.
It still serves the old publication; this review does not certify every old URL.
